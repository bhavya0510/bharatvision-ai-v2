# Bharat Vision AI v2 🇮🇳

An AI-powered web platform celebrating and visualizing Indian cultural heritage, art styles, architecture, and folklore through generative AI and rich interactive media.

---

## 🌟 Overview

**Bharat Vision AI v2** provides an immersive, standalone web experience designed with rich Indian aesthetics, dynamic typography, and responsive controls. It allows creators, researchers, and enthusiasts to explore culturally grounded visual concepts inspired by India's monuments, traditions, and artistic movements.

### Key Highlights
- **Cultural Art Curation**: Explore visual motifs spanning Mughal architecture, temple art, folk styles, and regional celebrations.
- **Standalone & Portable**: Self-contained web application with zero external framework dependencies required for runtime.
- **Responsive Web Design**: Optimized for desktops, tablets, and mobile viewports with native touch interactions and collapsible navigation.
- **GitHub Pages Ready**: Features `index.html` configured for instant one-click hosting via GitHub Pages.

---

## 🚀 Getting Started

### Local Preview
Simply open `index.html` (or `Bharat Vision .html`) in any modern web browser:

```bash
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows
start index.html
```

Or serve using a lightweight static server (e.g. Python or Node):
```bash
# Using Python
python3 -m http.server 8000

# Using Node (npx)
npx serve .
```
Then navigate to `http://localhost:8000`.

## 🌐 Deploy to GitHub Pages

To make this live on the web for free:

1. Navigate to **Settings** > **Pages** inside this GitHub repository.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch: `main` and folder: `/ (root)`.
4. Click **Save**.
5. Your site will be live at:
   `https://bhavya0510.github.io/bharatvision-ai-v2/`
